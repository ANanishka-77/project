# Discussion Portal

A responsive web application that enables users to create, search, and manage discussion threads through an intuitive interface. The portal supports community interaction with upvote/downvote functionality and stores data locally to preserve discussions across browser sessions.

## Features

* Create and publish discussion posts
* Search discussions in real time
* Upvote and downvote posts
* Delete discussions
* Local Storage for persistent data
* Responsive and user-friendly interface

## Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* DOM Manipulation
* Local Storage

## Purpose

This project was built to strengthen core frontend development skills by implementing interactive UI components, event-driven functionality, and client-side data persistence without using external frameworks.
